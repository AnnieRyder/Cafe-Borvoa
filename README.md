☕ Café Borvoa - Cardápio Digital
Bem-vindo ao repositório do Café Borvoa, um cardápio digital interativo e responsivo, desenvolvido para oferecer uma experiência de pedido ágil e visualmente agradável para nossos clientes.

![Preview do Café Borvoa](./src/assets/Café%20Borvoa.png)

🚀 Sobre o Projeto
O Café Borvoa é uma aplicação web focada em proporcionar um cardápio moderno, onde o cliente pode visualizar categorias (Cafés, Bolos, Salgados), ver detalhes dos produtos e adicionar itens a uma sacola de compras de forma intuitiva.

O projeto foi construído priorizando a experiência mobile-first e a performance.

🛠️ Tecnologias Utilizadas
React.js: Biblioteca principal para construção da interface.

CSS Modules: Para estilização isolada e organizada.

Framer Motion: Para animações suaves no banner e transições de página.

Lucide React: Biblioteca de ícones moderna.

Context API: Para gerenciamento do estado do carrinho de compras.

✨ Funcionalidades
[x] Navegação Responsiva: Layout adaptado para celular, tablet e desktop.

[x] Menu Hambúrguer: Navegação simplificada em dispositivos móveis.

[x] Filtros por Categoria: Navegação rápida entre Cafés, Bolos, Salgados e Bebidas.

[x] Carrinho de Compras: Adição e cálculo automático do valor total do pedido.

[x] Design Premium: Interface com paleta de cores focada em cafeterias artesanais.
